TTT 低頻趨勢功能說明書

功能文件，不是 README。適用於 Windows App 內的「TTT 低頻趨勢」模組。

1. 文件定位

本文件說明目前 App 內 TTT 模組的所有使用功能、輸出欄位、操作方式與策略判斷邏輯。它不是安裝文件，也不是專案 README；它比較接近使用手冊、產品規格與復盤指南的混合版。

策略名稱 TTT 低頻趨勢，又稱 Taiwan Trend Tracking Strategy。
目前版本 Strategy Version: TTT v2.0
回測引擎 Engine: Position-Based
出場模式 Exit Mode: Close Confirm
部位精神 Position: Core/Mobile
核心原則：TTT 不是單純用 20MA 或量比買賣，而是以市場結構優先，搭配均線、突破、收盤位置、漲跌停語言、流動性與成交金額來判斷右側趨勢。

2. 目錄

介面總覽 股號查詢 掃描適合進場股票 圖片分析股票 最新決策邏輯 回測與交易紀錄 圖表功能 歷史與快取 欄位說明 策略細項 一致性設計 限制與注意事項

3. TTT 介面總覽

TTT 模組目前位於主分頁 TTT 低頻趨勢。底下再分成三個主要功能分頁：

分頁 用途 適合情境
股號查詢 輸入單一股票，執行 TTT 回測，顯示是否適合進場、加碼時機、策略結論、波段圖表與交易紀錄。 你已經有特定標的，例如 2330、6217、NVDA，想知道目前用 TTT 看起來怎樣。
掃描適合進場股票 掃描台股前 N 大股票，找出符合 TTT 進場結構的候選名單。 你不知道今天該看哪些股票，想讓系統從市場中先篩一輪。
依據上傳圖片分析股票 把截圖或貼上的圖片交給 LLM 辨識股號，再逐檔用同一套 TTT 邏輯回測與判斷。 你從券商、社群、看盤軟體截了一串股票清單，想快速得到每檔結論。
重要：三個分頁的策略結論應該使用同一套 TTT 最新決策邏輯。若某檔股票在單一查詢、掃描、圖片分析結果不一致，優先檢查共用決策函式與資料日期。

4. 股號查詢功能

股號查詢是 TTT 的單股分析入口。它包含市場切換、股號輸入、歷史快捷、年限設定、量比門檻，以及回測結果顯示。

4.1 台股 / 美股分開查詢

股號輸入區已分成兩個內部分頁：

內部分頁 輸入方式 歷史紀錄
台股查詢 可輸入股票代號或股名，支援自動提示，例如 2330｜台積電。 只顯示台股歷史。
美股查詢 可輸入美股代號或公司名提示，支援常用清單與查詢歷史，例如 NVDA｜NVIDIA Corporation。 只顯示美股歷史。

4.2 自動提示

  • 台股自動提示來自台股名稱快取、官方名稱映射、台股清單與 fallback 名稱。
  • 美股自動提示來自內建常用美股清單，以及你查詢過的美股歷史。
  • 台股提供「更新」按鈕，可以重新整理台股提示清單。
  • 輸入股號後按 Enter 可以直接開始回測。

4.3 回測設定

設定 說明
回測年數 決定單股回測抓取的歷史資料長度。適合用 1 年看近期波段，用 3 到 5 年觀察策略長期穩定性。
20日建議最低量比 用於最新決策與掃描篩選。量比 = 今日量 / 20 日均量。預設常用門檻為 1.2。

4.4 結果區塊

查詢完成後，右側會顯示：

  • 標的與股名。
  • 策略報酬、買進持有報酬、最大回撤、交易數與勝率。
  • 「是否適合進場」highlight 區塊。
  • 「加碼時機」highlight 區塊。
  • TTT 策略結論。
  • 波段圖表與交易紀錄。
問號提示：「是否適合進場」與「加碼時機」旁邊的 ? 用來顯示完整理由，避免主要畫面塞太多文字。

5. 掃描適合進場股票

掃描分頁用來從台股前 N 大股票中找出目前符合 TTT 進場結構的候選名單。

5.1 掃描流程

  1. 讀取或抓取台股前 N 大股票清單。
  2. 逐檔抓取價格資料。
  3. 盤中掃描時採用穩定收盤策略，避免開盤或盤中價格讓結果漂移。
  4. 執行單股 TTT 回測。
  5. 使用與股號查詢相同的最新決策邏輯產生進場、加碼、價量與理由。
  6. 將符合條件的結果顯示在掃描表格。

5.2 掃描設定

設定 說明
掃描前 N 大 可設定掃描台股前 100 到 1000 大。數字越大越完整，但耗時越長。
加碼狀態 可篩選全部、可加碼觀察、等待加碼、不適合加碼。
20日最低量比 表格篩選門檻。調高會保留較有量能的股票；調低可能需要重新掃描才會補回原本沒列出的股票。

5.3 掃描結果欄位

欄位 說明
股號股票代號，例如 2330.TW 或 6147.TWO。
股名台股使用繁體中文名稱；若官方名稱本身是英文，例如 JPP-KY，則保留英文。
進場狀態是否適合進場，例如「適合進場」。
加碼狀態目前持有者是否可加碼觀察、等待加碼或不適合加碼。
收盤日本次判斷使用的價格日期。台股盤中會傾向使用前一個穩定交易日。
收盤用於判斷的收盤價。
5MA / 20MA / 60MA主要均線結構。
20日量比今日量除以 20 日均量。
5日量比今日量除以 5 日均量，用於觀察短期爆發。
價量例如價漲且收盤強、爆量弱收、急跌縮量、漲停鎖住等。
成交金額收盤價乘以成交量，用於流動性檢查。
20MA 乖離現價距離 20MA 的百分比。
原因TTT 判斷摘要。

5.4 排序與操作

  • 可點擊欄位標題排序：5MA、20MA、60MA、20日量比、5日量比、價量、成交金額、20MA 乖離。
  • 排序循環為：升冪 → 降冪 → 回到原本策略排序。
  • 右鍵股票列可帶到 TTT 回測，也可立即回測。
  • 雙擊股票列會開啟 Yahoo 股票頁，例如 2103.TW 會開到 https://tw.stock.yahoo.com/quote/2103.TW。

5.5 掃描快取

掃描結果會依日期、策略版本、掃描數量、回測年數、量比門檻建立快取。當日同樣條件可以優先讀取快取，減少等待時間。

6. 依據上傳圖片分析股票

圖片分析分頁用於處理你貼上或上傳的股票清單截圖。LLM 只負責從圖片中辨識股票代號；真正的策略判斷仍由 TTT 程式邏輯產生。

6.1 支援的使用方式

  • 上傳圖片分析。
  • 直接從剪貼簿貼上圖片分析。
  • 支援多張圖片一組分析。
  • 分析結果直接顯示在頁面上，不只用 popup。

6.2 LLM 設定

設定 用途
LLM 提供者 例如 Google Gemini 或其他相容提供者。
API Key 用於呼叫模型辨識圖片中的股票代號。
Model 可選擇模型，例如 gemma-4-31b-it。

6.3 圖片分析結果

每一檔被辨識出的股票，都會走與股號查詢、掃描相同的 TTT 回測與最新決策。結果欄位包含：

  • 股號、股名。
  • 進場結論。
  • 加碼狀態。
  • 是否仍持有。
  • 策略報酬、買進持有、最大回撤、交易數。
  • 收盤價、收盤日與原因。

6.4 圖片組紀錄

每次上傳或貼上的圖片會形成一組圖片組紀錄。你可以勾選歷史圖片組重新分析，適合每天固定追蹤同一批股票截圖。

6.5 圖片股號紀錄

系統會記錄從圖片分析中出現過的股號，並在自己的分頁中顯示。雙擊紀錄可以帶回 TTT 查詢並回測。

錯誤處理：如果 LLM 回傳 HTTP 500 或辨識失敗，應顯示清楚錯誤，不應讓 UI 永遠卡在分析中。若部分股票已成功解析，仍應保留可用結果。

7. 最新決策邏輯

TTT 的最新決策用來回答兩件事：

  1. 這檔股票現在是否適合進場？
  2. 如果目前已持有，現在是否適合加碼？

7.1 是否適合進場

目前主要條件：

  • MA5 > MA10 > MA20，短均線形成右側多頭排列。
  • 收盤價突破近 20 日結構高點。
  • 收盤位置不能太弱，避免假突破或分歧。
  • 上影線不能太長，避免追在被倒貨的 K 線。
  • 不能是漲停打開後未回封的弱結構。
  • 成交金額需達最低流動性門檻，目前為 1 億。

7.2 加碼時機

加碼不是給空手者追價，而是給策略已持有者判斷是否增加部位。主要條件：

  • 目前必須是策略持有狀態。
  • 出現漲停鎖住、開板回封，或突破 10 日高點且收盤強。
  • 短均線結構完整。
  • 沒有爆量弱收或疑似派發。
  • 成交金額足夠。

7.3 價量結構分類

價量結構 意義
漲停鎖住籌碼鎖定強，量小不一定是壞事。
開板回封開板後仍有承接並回封，屬強勢結構。
價漲且收盤強買盤願意把價格推高，收盤位置健康。
急跌縮量可能是洗盤，需搭配是否站上 20MA 與結構低點。
爆量弱收警示可能是分歧或派發。
流動性 / 派發警示跌停或爆量跌破重要低點，風險較高。

8. 回測與交易紀錄

TTT 回測使用 position-based engine。這代表同一檔股票同一時間只會有一筆主倉，不會因為重複訊號而每天開一筆新交易。

8.1 回測輸出

輸出 說明
策略報酬依策略交易計算的總報酬。
買進持有同期間單純買進持有的報酬。
最大回撤依 equity curve 計算的策略最大回撤。
交易 / 勝率交易筆數與勝率。
策略結論含策略版本、期間、起始價、結束價、最新市場結構、是否適合進場與加碼時機。

8.2 交易紀錄欄位

欄位 說明
進場日策略建立部位的日期。
出場日策略出場或回測結束日期。
進場價回測中的進場價格。
出場價回測中的出場價格。
報酬該筆交易報酬。
進場原因例如初始突破、趨勢延續、回測 MA20 後守穩等。
出場原因例如趨勢結構破壞、流動性崩潰、回測結束仍持有等。

8.3 持有者建議

TTT v2 偏向保留核心部位，不會因為單日跌破 MA20 就直接全砍。它更接近：

  • 跌破 MA20 先減碼或觀察。
  • 3 日無法站回再降低部位。
  • 真正出貨或流動性崩潰才出清。
新買與已持有是兩件事：新買要保守，避免追高；已持有則要盡量讓獲利奔跑，但遇到結構破壞要處理。

9. 圖表功能

TTT 股號查詢內建波段圖表，用來視覺化策略與價格位置。

9.1 顯示內容

  • 收盤價線。
  • 20MA 線。
  • 買點標記。
  • 賣點標記。

9.2 滑鼠提示

滑鼠移到圖表上時，會顯示該日期的收盤價、20MA 與相關訊號資訊，類似股票軟體的游標讀值。

9.3 框選放大

  • 按住滑鼠左鍵拖曳可框選圖表區間並放大。
  • 雙擊圖表可重置縮放。

10. 歷史、快取與資料穩定性

10.1 股號查詢歷史

TTT 股號查詢歷史分成台股與美股兩份顯示，不會混在同一區。

  • 台股歷史會顯示股號與繁體中文股名。
  • 美股歷史會顯示美股代號。
  • 點擊歷史按鈕會帶入對應市場分頁。

10.2 圖片分析歷史

  • 圖片組紀錄：儲存每次上傳或貼上的圖片組。
  • 圖片股號紀錄：儲存圖片分析中辨識到的所有股號。

10.3 台股名稱快取

台股名稱透過統一名稱解析器取得，優先順序為：

  1. 即時記憶體快取。
  2. 本地 JSON 快取。
  3. TWSE / TPEx 官方資料。
  4. fallback table。
  5. 最後才顯示股票代號。

10.4 掃描結果快取

TTT 掃描結果會依條件快取，包含日期、策略版本、掃描 N、回測年數與量比門檻。

10.5 穩定收盤政策

台股掃描在盤中會優先使用前一個穩定交易日的收盤資料，避免今日開盤或盤中價格讓掃描結果一直跳動。

11. 常見欄位與名詞

名詞 說明
20日量比今日成交量 / 20 日平均成交量。用來看今天是否比近期長週期更有量。
5日量比今日成交量 / 5 日平均成交量。用來看短期爆發與短線熱度。
20MA 乖離現價相對 20MA 的距離。太高代表追價風險較高，但強趨勢股不能只用乖離判斷。
成交金額收盤價乘以成交量，用來判斷流動性是否足夠。
弱收收盤接近當日低點，通常代表上方賣壓或追價失敗。
強收收盤靠近當日高點，代表買盤願意推價。
漲停鎖住接近漲停且收在高位，台股強勢股中可能代表籌碼鎖定。
開板回封漲停打開後又收回高位，代表承接力強。
爆量弱收量明顯放大但收盤弱，可能是分歧、派發或假突破。

12. 策略細項摘要

12.1 進場架構

TTT v2 的進場不只看均線，也看市場結構。主要候選訊號包含：

訊號 用途
BREAKOUT突破 20 日結構高點且量能放大。
EARLY_ACCELERATION剛起漲、剛加速的早期加速段。
ACCELERATION主升段加速，沿短均線快速推升。
TREND_CONTINUATION錯過初始突破後，趨勢仍健康時的延續進場。
REENTRY停損後重新突破，提供再進場機制。
PULLBACK正常上升趨勢中的回測守穩。
MOMENTUM補漏用的小部位動能進場。

12.2 進場優先順序

目前設計精神為：先抓強突破與加速，再考慮趨勢延續、再進場、回測與動能補漏。

BREAKOUT → EARLY_ACCELERATION → ACCELERATION → TREND_CONTINUATION → REENTRY → PULLBACK → MOMENTUM

12.3 防追高與防震盪

  • Chop Filter：震盪區不輕易進場，除非是強勢突破。
  • Cooldown：出場後有冷卻期，避免剛賣完又被洗進去。
  • Big Win Protection：上一筆大賺後，只允許更嚴格的強突破，避免高檔震盪吐回獲利。
  • Momentum Guard：動能追價需要量能、不可太快、不可離 MA20 太遠。
  • Pullback Guard：Pullback 只能在明確上升趨勢中做，避免買到弱反彈。

12.4 出場與減碼

TTT v2 不把單日跌破 MA20 當成全出場理由。它使用核心/機動部位概念：

  • 跌破 MA20：先減碼或觀察。
  • 無法在數日內收復：再降低部位。
  • 爆量破壞、流動性崩潰、跌停鎖死、長期結構破壞：才出清。

12.5 高獲利保護

當獲利很大時，TTT 會更重視不要吐回太多：

  • 大幅獲利後若出現高風險結構，可以減碼。
  • 獲利超過 100% 後，會更重視 MA10 與 10 日低點類型的防守線。

13. 一致性設計

TTT 目前最重要的產品規則是：單股查詢、掃描結果、圖片分析結果，都應該使用同一套最新決策邏輯。

功能 資料來源 策略判斷
股號查詢 使用者輸入的單一股號。 回測後用最新一根 K 線跑 TTT 最新決策。
掃描 台股前 N 大股票。 逐檔回測與最新決策，並套用穩定收盤政策。
圖片分析 LLM 從圖片辨識出的股號。 逐檔回測與最新決策，不由 LLM 自行判斷買賣。
排錯方向：如果同一檔股票在三個地方結論不同，先確認資料日期是否相同，再確認量比門檻、穩定收盤政策與共用決策函式是否一致。

14. 限制與注意事項

  • TTT 是策略輔助工具，不是投資建議或保證獲利系統。
  • 掃描 1000 檔可能耗時，尤其網路或資料源較慢時。
  • 圖片分析依賴 LLM，若 API 失敗、模型不支援圖片或圖片太模糊，辨識結果可能失敗。
  • 美股名稱目前以常用 watchlist 與查詢歷史為主，不是完整美股全市場清單。
  • 台股名稱若官方快取尚未更新，新上市櫃股票可能暫時顯示代號。
  • 量比需要搭配價格方向與收盤位置：量比高但下跌弱收不一定是好事。
  • 盤中掃描會刻意避免使用不穩定盤中價，因此可能與即時看盤軟體略有差異。

15. 建議使用流程

  1. 每天收盤後先到「掃描適合進場股票」掃描台股前 N 大。
  2. 用加碼狀態與 20 日量比篩選較乾淨的候選股。
  3. 針對有興趣的股票右鍵帶到 TTT 股號查詢並回測。
  4. 查看是否適合進場與加碼時機的 highlight 區塊。
  5. 用圖表確認買賣點、20MA 與當前位置。
  6. 若是從看盤軟體或社群取得清單，直接用圖片分析批次處理。
  7. 保留圖片組紀錄，隔天可勾選同一組重新分析。
